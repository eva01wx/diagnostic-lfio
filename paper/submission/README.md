# CAS manuscript layouts

The author supplied Elsevier's official CAS 2.4 template download on 19 October 2026.
Its class/style bytes match those already used for the earlier CAS manuscripts.
The selected submission layout preserves the author's single-column review preference:
`Manuscript_CAS_single_column.pdf` (34 pages), with matching flat sources in
`Manuscript_CAS_single_column_sources.zip`. Its sole main file is `Manuscript.tex`.

`Manuscript_CAS_double_column.pdf` (19 pages) and its matching source ZIP are an alternative.
Both have numeric citations. The source ZIPs include class/style license notices,
all referenced tables/figures and bibliography files, a compiled BBL, and member checksums.
The code, data and numerical results are unchanged. The frozen source/code/record ZIPs
under `artifacts/` keep their previous hashes and elsarticle layout.

The publisher also distributes elsarticle and both single- and double-column CAS classes;
this does not establish that Knowledge-Based Systems mandates two columns.
The live journal guide returned HTTP 403 during verification.

- [Publisher LaTeX instructions](https://www.elsevier.com/researcher/author/policies-and-guidelines/latex-instructions)

This directory is limited to manuscript layouts and sources. Final submission declarations
are prepared separately. No public upload or journal submission has been performed.
